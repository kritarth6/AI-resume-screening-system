# 📄 AI Resume Screening System

This project builds a **Natural Language Processing (NLP) system** that automatically classifies resumes into job categories using machine learning.

The application is deployed as an **interactive Streamlit web application** where users can paste resume text and instantly receive a predicted job category.

# 📌 Project Overview

Recruiters receive thousands of resumes for different roles. Manually reviewing them is time-consuming.

This project demonstrates how **machine learning and NLP** can automate resume screening by predicting the most relevant job category for a resume.

---

# 🧠 Machine Learning Pipeline

1. Resume dataset preprocessing
2. Text cleaning and normalization
3. Feature extraction using **TF-IDF**
4. Model training using **Multinomial Naive Bayes**
5. Model evaluation
6. Model deployment using **Streamlit**
